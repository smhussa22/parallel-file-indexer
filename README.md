A parallel file indexer, created purely by me with no AI assistance whatsoever 😳😳

I feel like I've been using too much AI assistance on most of my work for the past year-ish, and so this project is to help me re-enforce that conceptual knowledge I do not want to lose.
This is 100% a learning project; I am taking it low and slow as it has no deadline, which gives me all the more reason to use purely my brain.

A parallel file indexer is just that; a file scanner that lets you search for files, except it is multithreaded for efficiency and uses a Postgres database to answer questions with SQL.
